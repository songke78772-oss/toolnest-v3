Create Burn-After-Reading Chat

Recommended: Use the CipherDeck tool on this site to send the password to participants in an encrypted way.

1. Set room options
Choose how many people can join, how long the room lasts, and pick your display name.

2. Create the room
Click Create Room. You’ll get one-time invite links. Share them only with people you want to join.

3. Chat
Everyone joins with a link. Messages disappear when the room expires or is dissolved.

4. Optional encryption
Enable Deep Encryption and set a short password. Only people who know the password can read messages.

Rooms are temporary. When the timer ends or the creator dissolves the room, all messages are permanently deleted.

Invite links work only while the room exists. After it expires, they become invalid.

Deep Encryption is client-side. If you lose the password, messages cannot be recovered.

Nothing is stored after the room ends.
