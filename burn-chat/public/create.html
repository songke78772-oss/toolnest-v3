Create Burn-After-Reading Chat

1. Set room options
Choose how many people can join, how long the room lasts, and pick your display name.

2. Create the room
Click Create Room. You’ll get a one-time invite link. Share it only with people you want to join.

3. Chat
Everyone joins with the link. Messages are temporary and disappear when the room expires or is dissolved.

4. Optional encryption
Enable Deep Encryption and set a short password. Only people who know the password can read messages.

Rooms are temporary. When the timer ends or the creator dissolves the room, all messages are permanently deleted. There is no history or recovery.

The invite link works only while the room exists. After it expires, the link becomes invalid.

Deep Encryption is client-side. If you lose the password, messages cannot be recovered.

100% temporary. Nothing is stored after the room ends.
